Coloque aqui os ZIPs estaduais do CAR de Minas Gerais para a ingestao local.

Os arquivos `.zip` desta pasta nao sao versionados porque podem passar de 100 MB e sao recusados pelo GitHub.
Use:

```bash
npm run car:ingest:check
npm run car:ingest
```

Camadas muito pesadas que nao devem entrar na ingestao podem ficar em uma pasta local ignorada, como `ignore/`.
